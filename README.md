# Pizza Room — система: шаг 1 (фундамент)

Сервер и база данных для кассы, склада, рецептов, аналитики и сайта.
Работает на Cloudflare (Workers + база D1, восстановление на любую минуту за 30 дней на платном тарифе).

## Что уже умеет
- Вход сотрудников по личному PIN; роли: владелец, менеджер, кассир, повар.
- Цены по каналам: зал/сайт (base), Wolt, Glovo, Bolt. Цену всегда считает сервер.
- Заказы со сквозной нумерацией; удалить заказ нельзя, только отменить с причиной.
- Только с PIN менеджера: отмена, уменьшение позиции после кухни, скидка (до 30%), списание.
- Оплата: наличные, карта, через площадку; комиссия площадки считается сама.
- Фискальный чек: касса печатает его и присылает номер; оплаты без чека видны владельцу.
- Склад: приход, автосписание по рецептам в граммах, списания с причиной, инвентаризация с недостачей в лари.
- Смена: открытие с суммой в кассе, закрытие вслепую — кассир не видит, сколько должно быть.
- Журнал действий: цепочка хешей, изменить или удалить нельзя, подделка обнаруживается.
- Отчёты: выручка по дням/месяцам/годам и каналам (общая и чистая), продажи по пиццам, отчёт по кассирам.
- Уведомления владельцу в Telegram: отмены, скидки, неверные PIN, недостача, итоги смены.

## Проверка на компьютере (нужен Node.js 22+)
    node test/run.mjs
Тест прогоняет работу кассы и 45 проверок, включая попытки обмана.

## Запуск на Cloudflare (делаем вместе на следующем шаге)
1. Аккаунт Cloudflare, тариф Workers Paid.
2. `npx wrangler d1 create pizzaroom` → вписать database_id в wrangler.toml.
3. `npx wrangler d1 execute pizzaroom --remote --file=schema.sql`
4. Первый владелец: `node scripts/make-owner.mjs "Имя" ВАШ_PIN > owner.sql`,
   затем `npx wrangler d1 execute pizzaroom --remote --file=owner.sql` и удалить owner.sql.
5. `npx wrangler deploy`
